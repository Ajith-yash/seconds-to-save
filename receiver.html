About the Project

Smart Ambulance Alert and Traffic Clearance System ("Clear the Way. Save a Life.") is a real-time emergency transit communication and route-corridor warning platform.

When an authorised ambulance operator activates Emergency Mode and begins a journey toward a hospital, the system broadcasts live GPS coordinates and OSRM route geometry over secure, token-authenticated Ably Realtime channels. Registered receivers positioned along the active route corridor receive immediate audio-visual and browser notifications to clear the roadway safely.

Privacy Policy

1. Geolocation Data: Receiver GPS coordinates are used strictly in real time within the user's browser session to compute proximity to active ambulance routes. Receiver locations are never broadcast publicly or sold.

2. Credential Security: User passwords are never stored in browser localStorage. Authentication and Ably token generation are handled via cryptographically signed serverless requests.

3. Local Storage Usage: Browser localStorage is used solely for non-sensitive preferences (such as remembered email address, notification corridor distance, and local alert history).

Terms and Conditions

1. Authorised Use: Only verified emergency vehicle operators are permitted to authenticate as Ambulance Drivers and publish live ambulance telemetry. Receivers are restricted by Ably token capabilities to subscribing only.

2. Road Safety Compliance: Motorists receiving an AMBULANCE APPROACHING alert must always obey traffic laws, check mirrors, and yield right-of-way only when safe to do so.

3. Service Availability: Real-time alerts while the web application is open are delivered via Ably Realtime. Background push notifications when the browser is completely closed require an additional Web Push server configuration.
